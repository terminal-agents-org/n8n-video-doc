# n8n-video-doc
# Claude-Design description of n8n project, rendered as html.
## Workflow: 
- Screenshot from n8n workflow overview.
- Exported workflow in n8n as json.
- Both as input files for Claude Design.
- Prompt to create a video explaining the workflow in Claude Design.
- Claude also provided speaker notes, these were turned into audio via Elevenlabs.
- Audio length was longer than Video material, but Claude Design synced Video with Audio (manually provided time stamps for each speaker note).
- Output exported as html file, which is hosted via GitHub Page under 

https://terminal-agents-org.github.io/n8n-video-doc/
